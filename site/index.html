FAQ

Questions fréquentes

C'est vraiment gratuit ?

Oui, entièrement. Pas de pub, pas d'abonnement, pas de revente de données. Le code est public sur GitHub.

Pourquoi Windows affiche un avertissement à l'installation ?

Windows prévient pour toute appli qui n'a pas de signature numérique payante. C'est normal pour un projet indépendant : clique sur « Informations complémentaires » puis « Exécuter quand même ».

Est-ce que mes extensions Chrome fonctionnent ?

La plupart, oui : gestionnaires de mots de passe, traducteurs, mode sombre… Ouvre le Chrome Web Store depuis le menu et clique sur « Ajouter à Chrome ». Quelques extensions très liées à Chrome peuvent ne pas tout faire.

Maxou's Nav collecte-t-il mes données ?

Non. Aucune statistique, aucun suivi : Maxou's Nav ne contacte que GitHub (pour les mises à jour) et les listes de protection. Il envoie même aux sites le signal « Ne vendez pas mes données » (Global Privacy Control).

Comment se font les mises à jour ?

Maxou's Nav vérifie régulièrement s'il existe une nouvelle version, la télécharge en arrière-plan, vérifie qu'elle est intacte et l'installe au prochain redémarrage.
